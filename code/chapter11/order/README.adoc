= Order Service
:toc: left
:icons: font
:source-highlighter: highlightjs

A Jakarta EE and MicroProfile-based REST service for order management in the Liberty Rest App demo.

== Features

* Provides CRUD operations for order management
* Tracks orders with order_id, user_id, total_price, and status
* Manages order items with order_item_id, order_id, product_id, quantity, and price_at_order
* Uses Jakarta EE 10.0 and MicroProfile 7.1
* Runs on Open Liberty runtime

== Running the Application

There are multiple ways to run the application:

=== Using Maven

[source,bash]
----
cd order
mvn liberty:run
----

=== Using the provided script

[source,bash]
----
./run.sh
----

=== Using Docker

[source,bash]
----
./run-docker.sh
----

This will start the Open Liberty server on port 8050 (HTTP) and 8051 (HTTPS).

== API Endpoints

[cols="2,4,4", options="header"]
|===
| Method | URL | Description

| GET
| /api/orders
| Get all orders

| GET
| /api/orders/{id}
| Get order by ID

| GET
| /api/orders/user/{userId}
| Get orders by user ID

| GET
| /api/orders/status/{status}
| Get orders by status

| POST
| /api/orders
| Create new order

| PUT
| /api/orders/{id}
| Update order

| DELETE
| /api/orders/{id}
| Delete order

| PATCH
| /api/orders/{id}/status/{status}
| Update order status

| GET
| /api/orderItems/order/{orderId}
| Get items for an order

| GET
| /api/orderItems/{orderItemId}
| Get specific order item

| POST
| /api/orderItems/order/{orderId}
| Add item to order

| PUT
| /api/orderItems/{orderItemId}
| Update order item

| DELETE
| /api/orderItems/{orderItemId}
| Delete order item
|===

== Testing with cURL

=== Create new order

[source,bash]
----
curl -X POST http://localhost:8050/order/api/orders \
  -H "Content-Type: application/json" \
  -d '{
    "userId": 1,
    "totalPrice": 149.98,
    "status": "CREATED",
    "orderItems": [
      {
        "productId": 101,
        "quantity": 2,
        "priceAtOrder": 49.99
      },
      {
        "productId": 102,
        "quantity": 1,
        "priceAtOrder": 50.00
      }
    ]
  }'
----

=== Get all orders

[source,bash]
----
curl -X GET http://localhost:8050/order/api/orders
----

=== Get order by ID

[source,bash]
----
curl -X GET http://localhost:8050/order/api/orders/1
----

=== Get orders by user ID

[source,bash]
----
curl -X GET http://localhost:8050/order/api/orders/user/1
----

=== Update order

[source,bash]
----
curl -X PUT http://localhost:8050/order/api/orders/1 \
  -H "Content-Type: application/json" \
  -d '{
    "userId": 1,
    "totalPrice": 149.98,
    "status": "PAID"
  }'
----

=== Get items for an order

[source,bash]
----
curl -X GET http://localhost:8050/order/api/orderItems/order/1
----

=== Add item to order

[source,bash]
----
curl -X POST http://localhost:8050/order/api/orderItems/order/1 \
  -H "Content-Type: application/json" \
  -d '{
    "productId": 103,
    "quantity": 1,
    "priceAtOrder": 29.99
  }'
----

=== Update order item

[source,bash]
----
curl -X PUT http://localhost:8050/order/api/orderItems/1 \
  -H "Content-Type: application/json" \
  -d '{
    "orderId": 1,
    "productId": 103,
    "quantity": 2,
    "priceAtOrder": 29.99
  }'
----

=== Update order status

[source,bash]
----
curl -X PATCH http://localhost:8050/order/api/orders/1/status/SHIPPED
----

=== Delete order item

[source,bash]
----
curl -X DELETE http://localhost:8050/order/api/orderItems/1
----

=== Delete order

[source,bash]
----
curl -X DELETE http://localhost:8050/order/api/orders/1
----
